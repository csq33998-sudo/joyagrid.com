Scope

What is reviewed in an update

A category review checks navigation, card labels, useful context, and obvious dead destinations within the stated area. A guide edit checks the explanation, examples, risk notes, and links named in that entry. Reviews are scoped rather than site-wide unless the note explicitly says otherwise. If a correction changes the meaning of advice, the description should explain the corrected point instead of presenting the page as newly published.

Reader checks

Verify changing information yourself

External sellers and agent services can change prices, inventory, payment methods, shipping lines, prohibited-item rules, return handling, and support without notice. Before relying on an older entry, open the current destination and review the information that affects your item and country. Report a broken route or material error with the page URL and supporting detail so the specific record can be reviewed.
