GSC review process:

1. Wait 7-14 days after deployment before judging results.
2. In Google Search Console, filter Performance by Page.
3. Export queries for each high-impression page.
4. Compare impressions, average position, CTR, query mix, and whether Google rewrote the title/snippet.
5. Keep a title if CTR improves and average position/query mix are similar.
6. Test one major title/description change per page per cycle.

Decision rules:

- If average position improves but CTR stays weak, make the title more benefit-led.
- If Google rewrites the title, align visible H1 and first paragraph more closely with the intended SERP title.
- If a page ranks for a different query cluster than expected, rewrite the meta description around the actual query intent.
- Avoid repeating the same exact title formula across all pages.
